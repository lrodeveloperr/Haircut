# Owner approval and release constraints

Before implementing code, monetization, gameplay, audience/rating, public metadata or release changes, explain the exact proposal and material gameplay/revenue impact and obtain the owner's explicit approval. An audit request does not authorize redesigning the product. Do not repeat approval requests for the same concrete action already explicitly authorized.

The later approved baseline uses one completed earned-reward video for each of the two selected daily items; preserve earned-reward callbacks and existing natural-break interstitial rules until the separately locked rewarded/interstitial router is implemented and tested. Keep debug on Google's test IDs; never test live ads.
